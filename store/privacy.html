Privacy Policy for PaperCard

Last updated: September 28, 2026

PaperCard (formerly “X Post Share Card”) is a Chrome extension that helps users create a polished PNG image card from a post on X/Twitter, Reddit, Threads, Instagram, Bluesky, Weibo, Zhihu or Xiaohongshu, or from text the user selects on a web page. The generated image can be copied to the clipboard, previewed, or downloaded by the user.

Single Purpose

The extension has one purpose: to turn user-selected web content into a local image share card.

Data Collection

PaperCard does not collect, store, sell, transfer, or share user data.

The extension does not use analytics, tracking pixels, advertising SDKs, external databases, or remote logging services. The developer does not operate any server that receives data from the extension.

How the Extension Uses Page Content

When the user clicks “Share as image” in the share menu of a post on X/Twitter, the extension reads that post as it is displayed in the browser so it can render the card. This may include:

  • Post text
  • Author name, handle, and profile picture
  • Post date
  • Engagement counts such as replies, reposts, likes, bookmarks, and views
  • Images attached to the post

When the user clicks “Share as image” in the share menu of a post on Reddit, the extension reads that post as it is displayed in the browser. This may include:

  • Subreddit name and community icon
  • Author username
  • Post title and body text
  • Post date
  • Upvote and comment counts
  • Images attached to the post, or the preview image of a video post

When the user chooses “Share this post as image” from the right-click menu on a post on Threads, Instagram, Bluesky, Weibo, Zhihu or Xiaohongshu, or presses the extension's keyboard shortcut while the pointer is over such a post, the extension reads that one post as it is displayed in the browser. This may include the author's name, handle and profile picture, the post title and text, the post date, engagement counts shown on the post (such as likes, comments, reposts, upvotes or saves), and images attached to the post. On X/Twitter, if the user chooses “Whole thread”, the extension reads the author's consecutive posts in that thread that are displayed on the page.

When the user selects text on another website and chooses “Create share card” from the right-click menu, the extension reads the selected text, the page title, the site icon, and the page URL so it can render the card.

This information is processed locally in the user's browser only to generate the PNG image and its preview. It is not sent to the developer or to any third-party server. If the user turns on the optional QR code, the post or page URL is encoded into the image locally.

Loading Post Images

To draw a post's images and avatars into the card, the extension downloads them directly from the servers where each site already hosts them (for example pbs.twimg.com, i.redd.it, cdn.bsky.app, cdninstagram.com, sinaimg.cn, zhimg.com and xhscdn.com). These are the same requests the browser makes when displaying the post. No other data is included in these requests, and cookies are not sent. Weibo's image server only answers requests that identify weibo.com as the referring site, so for requests the extension itself makes to sinaimg.cn it sets the Referer header to https://weibo.com/; this header contains no user data.

Settings Storage

The extension saves the user's card preferences (card style, light/dark theme, footer fields, and whether to show a QR code or a “Made with PaperCard” credit line) using Chrome's built-in chrome.storage.sync. If Chrome sync is enabled, Chrome may sync these preferences across the user's own browsers. These preferences contain no personal information and are never sent to the developer.

Clipboard Access

The extension uses clipboard access only after the user chooses the “Share as image” or “Create share card” action. Clipboard access is used only to place the generated PNG image on the user's clipboard. The extension never reads the clipboard.

Permissions

  • x.com, twitter.com, reddit.com, threads.com, instagram.com, bsky.app, weibo.com, zhihu.com, xiaohongshu.com: add the “Share as image” menu items and read the post the user chose.
  • pbs.twimg.com, redd.it, redditmedia.com, redditstatic.com, cdn.bsky.app, cdninstagram.com, fbcdn.net, sinaimg.cn, zhimg.com, xhscdn.com: load post images and avatars so they can be rendered into the card.
  • declarativeNetRequestWithHostAccess: sets the Referer header described above on the extension's own image requests to sinaimg.cn. It is never applied to requests made by web pages.
  • activeTab and scripting: on other websites, used only after the user selects text and clicks the extension's right-click menu item.
  • contextMenus: adds the “Create share card” and “Share this post as image” right-click menu items.
  • clipboardWrite: copies the generated image to the clipboard.
  • storage: saves the card preferences described above.

Remote Code

PaperCard does not execute remote code. All JavaScript and CSS used by the extension are included in the extension package.

Data Retention

Because the extension does not collect or transmit user data, it does not retain user data. Generated images exist only in the user's clipboard, the on-page preview, or files the user chooses to download.

Affiliation
